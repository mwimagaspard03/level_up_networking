# NETWORKING LEVEL UP — Design System V1

Première couche visuelle pour l’application Next.js App Router : identité, tokens CSS, composants partagés et page d’accueil responsive. Interface française, sombre par défaut, préparée pour une future traduction anglaise. Aucun pictogramme/logo illustratif et aucune inscription publique.

Les polices Space Grotesk et Inter sont déclarées avec des polices de secours système ; aucune police distante n’est chargée. Les illustrations de démonstration sont générées en CSS.
